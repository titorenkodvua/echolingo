# 📋 Полная сводка полей материалов Echolingo

## 🎯 Обзор

Материалы Echolingo содержат расширенный набор полей для полной категоризации, многоязычности и персонализации обучения. **Описания генерируются автоматически** из транскрипции Gladia API.

## 📊 Все поля материалов

### 🔑 **Основные поля (обязательные)**

| Поле | Тип | Описание | Пример |
|------|-----|----------|---------|
| `id` | string | Уникальный идентификатор | `"749ffe0f-d3e4-48a9-9187-3a3f03a0dbee"` |
| `title` | string | Название материала | `"Польский диалог о погоде"` |
| `audioFileName` | string | Имя аудиофайла | `"weather-dialogue.mp3"` |
| `transcriptionId` | string | ID транскрипции | `"transcription-123.json"` |

### 📝 **Описательные поля**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `description` | string | **Автоматически** | Описание материала | `"Deszcz i niechęć do poniedziałku..."` |
| `tags` | array[string] | Нет | Теги для категоризации | `["польский", "диалог", "погода"]` |
| `category` | string | Нет | Основная категория | `"conversation"`, `"news"`, `"business"` |
| `author` | string | Нет | Автор материала | `"Echolingo Team"` |

### 🌍 **Языковые поля**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `sourceLanguage` | string | Нет | Исходный язык | `"pl"`, `"en"`, `"ru"` |
| `targetLanguage` | array[string] | Нет | Целевые языки перевода | `["ru", "en", "de"]` |

### 📊 **Уровень сложности**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `difficultyLevel` | string | Нет (B1) | Уровень по CEFR | `"A1"`, `"A2"`, `"B1"`, `"B2"`, `"C1"`, `"C2"` |

### ⏱️ **Временные поля**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `duration` | number | Нет | Длительность в секундах | `180` (3 мин) |
| `estimatedTime` | number | Нет | Время изучения в минутах | `15` |

### ⭐ **Рейтинговые поля**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `averageRating` | number | Нет (0) | Средняя оценка (0-5) | `4.5` |
| `ratingCount` | integer | Нет (0) | Количество оценок | `12` |

### 🎯 **Поля для shadowing**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `recommendedRepetitions` | integer | Нет (3) | Рекомендуемые повторения | `5` |

### 🔒 **Права доступа**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `userId` | string | Нет (anonymous) | ID пользователя | `"user-123"` |
| `isPublic` | boolean | Нет (false) | Публичный ли материал | `true` |

### 📈 **Статистические поля**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|
| `status` | string | Нет (active) | Статус материала | `"active"`, `"archived"`, `"deleted"` |
| `playCount` | integer | Нет (0) | Количество прослушиваний | `42` |
| `lastPlayed` | string | Нет (null) | Время последнего прослушивания | `"2025-06-27T22:04:15.272Z"` |

### ⏰ **Временные метки**

| Поле | Тип | Обязательное | Описание | Пример |
|------|-----|--------------|----------|---------|

| `updatedAt` | string | Да | Время обновления | `"2025-06-27T22:04:15.284Z"` |

## 🤖 Автоматическое получение описаний

### Как это работает

1. **Gladia API** (приоритет 1)
   - Автоматически создает краткое описание на основе транскрипции
   - Высокая точность (confidence: 0.9)
   - Описание на языке оригинала

2. **Генерация из транскрипции** (fallback)
   - Если Gladia не предоставил описание, генерируется из первых 20 слов
   - Средняя точность (confidence: 0.7)

### Примеры автоматических описаний

**Из Gladia API:**
```
"Osoba rozważa wybór szkoły językowej i planuje przyszłość. 
Mówi o swoim rosnącym intelekcie, kinie i potrzebie większego mieszkania."
```

**Сгенерированное из транскрипции:**
```
"A myślałem, że to ja będę wybierał szkołę językową dla siebie. 
No właśnie. Ty będziesz studiował w najlepszym centrum języka..."
```

## 🎯 Рекомендации по использованию

### 📊 **Уровни сложности и повторения**

| Уровень | Рекомендуемые повторения | Типичные материалы |
|---------|-------------------------|-------------------|
| A1-A2 | 3-5 | Базовые фразы, приветствия |
| B1-B2 | 5-8 | Диалоги, новости, бытовые темы |
| C1-C2 | 8-12 | Академические материалы, лекции |

### 🌍 **Поддерживаемые языки**

- **Европейские**: `pl`, `en`, `ru`, `de`, `fr`, `es`, `it`, `pt`
- **Азиатские**: `ja`, `ko`, `zh`, `ar`

### 📂 **Категории материалов**

- `conversation` - Диалоги, разговоры
- `news` - Новости, репортажи
- `business` - Деловые материалы
- `education` - Образовательный контент
- `entertainment` - Развлекательный контент
- `travel` - Путешествия, туризм

## 🔧 Примеры использования

### 🆕 **Создание материала с автоматическим описанием**

```javascript
POST /api/materials
{
  "title": "Приветствие на польском",
  "audioFileName": "greetings.mp3",
  "transcriptionId": "greetings.json",
  "sourceLanguage": "pl",
  "targetLanguage": ["ru", "en"],
  "duration": 60,
  "estimatedTime": 10,
  "difficultyLevel": "A1",
  "category": "conversation",
  "recommendedRepetitions": 3,
  "tags": ["польский", "приветствие", "базовый"],
  "isPublic": true
  // description будет сгенерирован автоматически!
}
```

### 🎓 **Создание академического материала**

```javascript
POST /api/materials
{
  "title": "Лекция по истории Польши",
  "audioFileName": "history-lecture.mp3",
  "transcriptionId": "history-lecture.json",
  "sourceLanguage": "pl",
  "targetLanguage": ["en"],
  "duration": 1800,
  "estimatedTime": 120,
  "difficultyLevel": "C1",
  "category": "education",
  "recommendedRepetitions": 10,
  "author": "Dr. Jan Kowalski",
  "tags": ["польский", "история", "академический"],
  "isPublic": true
}
```

### 💼 **Создание делового материала**

```javascript
POST /api/materials
{
  "title": "Деловая встреча на польском",
  "audioFileName": "business-meeting.mp3",
  "transcriptionId": "business-meeting.json",

  "estimatedTime": 30,
  "difficultyLevel": "B2",

  "recommendedRepetitions": 7,
  "tags": ["польский", "бизнес", "деловая встреча"],
  "isPublic": true
}
```

## ✅ Валидация

### 🔢 **Числовые ограничения**

- `averageRating`: 0-5
- `recommendedRepetitions`: 1-20
- `duration`: 0-7200 секунд (2 часа)
- `estimatedTime`: 0-480 минут (8 часов)

### 🌍 **Языковые ограничения**

- Поддерживаются только валидные языковые коды
- `targetLanguage` должен быть массивом

### 📊 **Уровни сложности**

- Только: `A1`, `A2`, `B1`, `B2`, `C1`, `C2`
